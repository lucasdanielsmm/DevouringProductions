Antes del Amanecer

"La muerte no es el final... es otra lente."

Atrapado en un cementerio maldito, deberás usar la máscara de tu hermano para ver el mundo espiritual. Un proyecto de Terror Psicológico desarrollado en Unity 3D para la Global Game Jam. Explora la delgada línea entre la realidad y el ritual.

Desarrollo Técnico & Mecánicas

1. Sistema de "Visión Dual" C# / Scripting

  • Implementación de una mecánica de cambio de realidad en tiempo real usando State Pattern.
  • Gestión de referencias dinámicas para alternar entre objetos físicos y espectrales sin perder el estado del juego.
  • Uso creativo de Layer Masking y cambios de materiales para revelar pistas ocultas tras la máscara.

2. Atmósfera e Inmersión 3D Unity HDRP/URP

  • Diseño de iluminación dinámica para generar tensión (luces parpadeantes, sombras duras).
  • Implementación de Post-Processing Profiles personalizados para diferenciar visualmente el mundo de los vivos del espiritual (aberración cromática, viñeteado).
  • Sistemas de partículas para niebla y efectos rituales.

3. Narrativa & Eventos Game Logic

  • Sistema de investigación Point & Click integrado en entorno 3D.
  • Programación de eventos temporales (Timelines) para la aparición progresiva de texto narrativo.
  • Secuencias de Jumpscares disparadas por Triggers espaciales y condiciones lógicas del jugador.
